# KFT Uduboh Nigeria Limited — Official Corporate Website

> **"Built with strength, driven by precision, committed to delivery."**

A production-grade, 9-page corporate website designed and built specifically for **KFT Uduboh Nigeria Limited**, incorporating the company's verified brand identity, official color palette (`#0A3982`, `#D71920`, `#333333`), geometric logo formation standards, and dual operational hubs in **Effurun** and **Gbaramatu Kingdom, Delta State**.

---

## 1. Brand Identity & Design System

The digital presence is directly derived from the official *KFT Brand Identity & Guidelines* and corporate credentials:

- **Official Legal Name**: KFT Uduboh Nigeria Limited
- **Brand Slogan**: *"Built with strength, driven by precision, committed to delivery."*
- **Typography Standard**: **Montserrat** (Google Fonts) — clean, geometric, authoritative sans-serif hierarchy across all headings, body text, and technical specifications.
- **Color System**:
  - **KFT Navy Blue (`#0A3982`)**: Primary corporate color representing institutional stability, engineering authority, and marine supremacy.
  - **KFT Crimson Red (`#D71920`)**: Accent energy color inspired by forward mechanical drive, decisive execution, and high-visibility field safety.
  - **Industrial Charcoal (`#333333`)**: Neutral body text and structural grounding.
  - **Deep Burgundy (`#170006`)**: Secondary dark background tone for premium contrast.
- **Logomark Story**: Inspired by the articulated **boom and dipper arm** of heavy hydraulic excavators (symbolizing power and precision) framed within a **perfect square** (representing balance, governance, and structural reliability).

## 3. Technology Stack

- **Framework**: React 18 with TypeScript
- **Bundler & Dev Server**: Vite 5
- **Styling**: Tailwind CSS with custom KFT brand tokens
- **Icons**: Lucide React
- **Typography**: Montserrat (Google Fonts)
- **SEO & Metadata**: JSON-LD Structured Data (`GeneralContractor`), OpenGraph, Twitter Cards, `robots.txt`, and XML Sitemap (`sitemap.xml`).

---

## 4. Local Development & Production Build

### Prerequisites
Node.js (v18+) and npm.

### Running in Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```
Generates an optimized, tree-shaken static bundle in the `dist/` directory ready for any web server or static hosting platform.

### Previewing the Production Build
```bash
npm run preview
```

---

## 5. Deployment Options

The build output in `dist/` is 100% static and can be deployed instantly to:

- **Vercel / Netlify**: Simply link this repository or upload the `dist` folder.
- **Cloudflare Pages**: Set build command to `npm run build` and output directory to `dist`.
- **cPanel / Apache / Nginx**: Upload the contents of `dist/` directly to `public_html`.
